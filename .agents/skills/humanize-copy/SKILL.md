# Humanize Copy Skill

Use this skill whenever drafting, reviewing, or editing user-facing website copy, blog posts, documentation, guides, or component text.

## Core Rules

1. **Strictly Ban Em-Dashes (`—`) and En-Dashes (`–`)**:
   - Split run-on clauses into two distinct sentences using periods.
   - Use commas only where grammatically natural.

2. **Ban AI Buzzwords**:
   - `testament` -> evidence, record, history
   - `delve` -> explore, inspect, examine
   - `tapestry` -> tradition, system, history
   - `monumental` -> large, permanent, central
   - `bespoke` -> custom, handcrafted, made-to-order
   - `seamless / seamlessness` -> smooth, direct, automatic
   - `elevate` -> improve, raise, enhance
   - `beacon` -> landmark, symbol, center
   - `pedagogical instrument` -> educational reference, teaching tool
   - `living horology` -> Vedic timekeeping, astronomical clocks

3. **Active Voice & No Gerund-Heavy Leads**:
   - Instead of: *"Synchronizing temple rituals..."*
   - Write: *"Tracks temple rituals..."* or *"Built to track temple rituals..."*

4. **SEO & AEO Architecture**:
   - Retain all core technical entities: *Surya Siddhanta*, *Ujjain 0° meridian*, *Nakshatra*, *Tithi*, *Panchang*, *Muhurta*, *Ahoratra*, *Vikram Samvat*.
   - Use clear Entity-Verb-Object structures so LLMs (ChatGPT, Perplexity, Gemini) can parse and cite direct facts.
